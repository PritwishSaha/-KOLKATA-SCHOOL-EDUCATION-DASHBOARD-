KOLKATA SCHOOL EDUCATION ANALYTICS DASHBOARD Project Report

Prepared by: Pritwish Saha Project Type: Data Analytics / Power BI
Tools: Power BI, Power Query, DAX, CSV

============================================================ 1. ABSTRACT
============================================================

The Kolkata School Education Analytics Dashboard is a Power BI-based
data analytics project developed to analyze the distribution of schools
and students across different boroughs and wards of Kolkata.

The project uses school-level data containing information such as school
code, school address, borough, ward number, school type, classes, and
number of students. The raw data was transformed and analyzed using
Power Query, DAX, and Power BI visualizations.

The final dashboard provides an interactive overview of school and
student distribution, allowing users to compare boroughs and wards,
analyze school types, and understand schools based on their student
population.

============================================================ 2.
INTRODUCTION
============================================================

Education infrastructure is an important part of urban development.
Kolkata contains schools distributed across different municipal boroughs
and wards. Understanding how schools and students are distributed can
provide useful insights into the city’s education infrastructure.

Raw educational datasets can be difficult to interpret directly. This
project transforms the raw school data into an interactive Power BI
dashboard so that important patterns and comparisons can be understood
more easily.

============================================================ 3. PROBLEM
STATEMENT ============================================================

The Kolkata school dataset contains information about schools, wards,
boroughs, school types, classes, and student populations. The objective

============================================================ 5. DATASET
DESCRIPTION ============================================================

The project uses the Kolkata_Schools dataset.

Important fields include:

-   SL No: Serial number of the record.
-   Borough: Municipal borough identifier.
-   Ward No: Municipal ward number.
-   School Code: School identifier/code.
-   School Address: Address of the school.
-   School Type: Type/ownership of the school.
-   Classes: Classes offered by the school.
-   No of Students: Number of students in the school.

Dashboard-level summary:

-   Total Schools: 259
-   Total Students: Approximately 28K
-   Total Boroughs: 15
-   Total Wards: 106

These values are based on the current Power BI dashboard.

============================================================ 7. DATA
CLEANING AND TRANSFORMATION
============================================================

The dataset was prepared before visualization.

Main data preparation activities include:

-   Checking data types.
-   Ensuring No of Students is numeric.
-   Keeping School Code as text because it contains codes such as
    001/001/BD.
-   Cleaning unnecessary spaces from text fields.
-   Checking missing or inconsistent values.
-   Preparing categorical fields for visualization.
-   Creating a Student_Size classification using Power Query.

Student_Size categories:

-   Very Small: 0-50 students
-   Small: 51-100 students
-   Medium: 101-150 students
-   Large: 151-200 students
-   Very Large: 200+ students

============================================================ 8. DAX
MEASURES ============================================================

Total Schools:

Total Schools = DISTINCTCOUNT(Kolkata_Schools[School Code])

Total Students:

Total Students = SUM(Kolkata_Schools[No of Students])

Total Boroughs:

Total Boroughs = DISTINCTCOUNT(Kolkata_Schools[Borough])

Total Wards:

Total Wards = DISTINCTCOUNT(Kolkata_Schools[Ward No])

Average Students per School:

Average Students per School = DIVIDE([Total Students], [Total Schools])

============================================================ 10.

10.1 Schools by Ward

The Schools by Ward visualization compares the number of schools across

10.2 Students by Borough

The Students by Borough visualization compares student populations

10.4 Students by Ward

10.5 Schools by Type

============================================================ 13.
LIMITATIONS ============================================================

The current project has several limitations:

1.  The dataset is a static dataset rather than a live real-time data
    source.
2.  Latitude and longitude coordinates are not available.
3.  Teacher information is not available.
4.  Classroom capacity information is not available.
5.  Historical student enrollment data is not available.
6.  Ward-level population data is not available.
7.  School performance and quality indicators are not available.
8.  The current dataset cannot independently determine whether a school
    is overcrowded because school capacity data is not available.

Therefore, the project should be treated as a descriptive analytics
dashboard rather than a complete education planning or overcrowding
model.

distribution by ward, student population by borough and ward, school
types, and school-size categories.

DAX, data visualization, and Power BI dashboard development.
